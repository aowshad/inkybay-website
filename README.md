# InkyBay website

Locked homepage design for InkyBay (product customizer for Shopify), ready to be rebuilt as the full site.

- Open `reference/homepage.html` in a browser to see the locked homepage (light/dark follow your device).
- Edit `src/template.html` and run `python3 build.py` to regenerate the reference.
- Read `CLAUDE.md` before building: tokens, components, section behaviours and rules.
